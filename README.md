
# Supervised Learning: NYC Building Façade Compliance Analysis

**Team:** Amelia, Jerome, Kazuko, Sahil

**Course:** AI Methods I – Day 2: Supervised Learning, Models, Validation & Metrics (IAAC MaAI 2026/27)

## Project Overview

This project explores NYC DOB NOW Façade Compliance Filings using supervised machine learning.

The objective is to investigate building façade compliance data, identify patterns, and develop predictive models based on the available features.

## Dataset

**Source:** NYC Open Data

**Dataset:** DOB NOW: Safety – Facades Compliance Filings

**Link:** https://data.cityofnewyork.us/d/xubg-57si

## Methodology

1. Data collection and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature selection and target definition
5. Supervised learning model training
6. Model validation and evaluation
7. Results and conclusions
